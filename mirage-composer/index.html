METAL SHADER

もっと踏み込むなら、
シェーダーも

Want to go further?
Write a shader.

コードを書きたいときは Metal Shader パッチに mainImage を。その場でコンパイルして、ほかのパッチとつなげます。

When you want code, write mainImage in a Metal Shader patch. It compiles as you type and wires into everything else.

float4 mainImage(float2 uv, constant Uniforms& u,
                 texture2d<float> image, sampler s) {
    float2 p = (uv - 0.5) * float2(u.resolution.x / u.resolution.y, 1.0) * 3.0;
    float  t = u.time * (0.4 + u.params.x);
    float  v = sin(p.x + t) + sin(p.y * 1.3 - t * 1.1)
             + sin(length(p) * 2.0 - t * 1.7);
    float3 col = 0.5 + 0.5 * cos(v + float3(0.0, 2.0, 4.0));
    return float4(col * u.color.rgb, u.color.a);
}

よくある質問

Questions

本当に無料ですか？

はい。アプリ内の課金もありません。1度入手すれば、Mac と iPhone・iPad の両方で使えます。

コードを書けなくても使えますか？

使えます。パッチを置いて線でつなぐだけで作れます。まずは File › Demos のサンプルを開いて、中のつながりを見てみてください。

MIDI・OSC・Syphon は使えますか？

今は使えません。音にはマイクから反応できます。

作品を VJ で使うには？

保存した作品（.mcomp）を ONOM FLOW の素材フォルダに入れると、ジェネ素材として8レイヤーに出せます。動画に書き出して、ほかのソフトで使うこともできます。

Is it really free?

Yes, with no in-app purchases. One download covers Mac, iPhone and iPad.

Do I need to code?

No. Drop in patches and connect them. Start by opening a sample from File › Demos and looking at how it's wired.

MIDI, OSC or Syphon?

Not at the moment. Compositions can react to sound through the microphone.

How do I use compositions for VJing?

Put saved compositions (.mcomp) in ONOM FLOW's media folder and play them as generative clips across eight layers. You can also export them as movies for other software.
